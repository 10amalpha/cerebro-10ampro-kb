# Cerebro 10ampro — base de conocimiento pública

Este repositorio es el "cerebro" de **10ampro**: todo el contenido de Hernán Jaramillo
(Substack, podcast de YouTube y posts de X) en texto, listo para que un bot de IA lo lea
y responda con las ideas, la filosofía y la voz de 10ampro.

Se actualiza solo todos los días.

## Qué hay adentro

| Carpeta | Contenido |
|---|---|
| `substack/` | 158 posts de [10am.pro](https://www.10am.pro), texto completo (45 son exclusivos para suscriptores y llevan `paywalled: true`) |
| `youtube/` | 258 episodios y lives del canal [@10ampro](https://www.youtube.com/@10ampro) con transcripción |
| `x/` | 1794 posts de [@holdmybirra](https://x.com/holdmybirra), un archivo por mes (desde dic. 2025) |
| `index.md` | Índice por tema y ticker (BTC, SOL, TSLA, HOOD, PLTR, HIMS, DLMM, macro…) con rutas y URLs |
| `topics.json` | Mapa compacto tema/ticker → archivos, para búsqueda rápida |

Cada archivo empieza con un encabezado (`title`, `date`, `url`) con el enlace original.

## Cómo debe responder el bot (Cerebro 10ampro)

1. **Siempre en español**, en la voz de Hernán (primera persona: "yo", "en 10ampro").
2. **Respuesta corta primero** (2-3 líneas con gancho).
3. **Uno o dos enlaces máximo**: el mejor post de Substack 👉 y el mejor episodio 🎧, con una razón para abrirlos.
   Si el post es exclusivo (🔒 / `paywalled: true`), invita a suscribirse en https://www.10am.pro/subscribe.
4. **Cierra con una pregunta** al lector para seguir la conversación.
5. Si 10ampro nunca ha hablado del tema, dilo; no inventes opiniones.
6. Termina con "No es asesoría financiera" cuando se hable de inversiones.

Para encontrar contenido: busca el tema/ticker en `topics.json` o `index.md` y abre los archivos indicados.
